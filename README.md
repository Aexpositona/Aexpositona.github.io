# alejandro-exposito-navarro.github.io

Web personal de una página. Estática, sin dependencias.

## Publicar en GitHub Pages

1. Crear un repo llamado `Aexpositona.github.io` (para servir en la raíz del dominio) o cualquier nombre (se servirá en `/<repo>/`).
2. Subir el contenido de esta carpeta a la rama `main`.
3. Settings -> Pages -> Source: `Deploy from a branch` -> `main` / `/ (root)`.
4. La web queda en `https://aexpositona.github.io/`.

## Archivos

- `index.html` — la web (CSS y JS embebidos).
- `foto-perfil.png` — foto.
- `CV-Alejandro-Exposito-Navarro.pdf` — CV enlazado desde el botón.
- `.nojekyll` — evita el procesado Jekyll de GitHub Pages.
